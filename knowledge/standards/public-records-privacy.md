# Principles

* Government web content and submissions may be public records. Assume anything stored can be requested.
* Collect the minimum personal data a form needs. Mark which fields are personal data in the form definition.
* Retention periods are a deployment setting, not hard-coded. Each document type declares a retention class.
* Meeting agendas and minutes are published as accessible documents with stable URLs.

# Open items

* Open-records law differs by jurisdiction. Counsel for each deployment must confirm what applies to web content, form submissions and logs before this file is marked stable.
* Keep jurisdiction-specific rules in deployment overlays, not in core.
