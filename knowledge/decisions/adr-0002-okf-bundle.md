# Decision

* Knowledge is stored as concept files under `knowledge/`, conforming to OKF v0.2. Each deployment gets its own overlay bundle under `deployments/`.
* `AGENTS.md` stays under 150 lines and routes agents into the bundle.
* Index files are generated by `npm run okf:index`. CI rejects stale indexes.
* House rules stricter than the spec: links must resolve, every directory has an index, requirements have IDs and tests.

# Notes

OKF is at an early version. Pin to v0.2 in the root `index.md` (`okf_version`) and re-read the spec before upgrading. The spec is permissive by design; the stricter checks live in `scripts/validate-okf.mjs`.

See [the reading order](/process/reading-order.md).
