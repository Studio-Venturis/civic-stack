# What it is

A way to tell the government about a non-emergency problem in a public place and see what happens next.

# Who can use it

Any resident or visitor.

# Steps

1. Choose a category and mark the location on a map or enter an address.
2. Describe the problem and add a photo if you can.
3. Submit and receive a reference number.
4. Staff route the report to the right team.
5. Track status updates until the issue is closed.

# Documents needed

None. A photo and a precise location help.

# Fees and timing

Free. Target response times are set by the owning department and are not stated in this example.

# Help and escalation

For emergencies, call the emergency number shown prominently on every page. Residents can always ask for a person.

# Not covered

Emergencies, crimes in progress and problems on private property.
