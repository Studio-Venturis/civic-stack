# When this applies

Any change to markup, styles, content types or document handling.

# Steps

1. Run the automated scan and fix every serious or critical finding.
2. Walk the primary task with the keyboard only.
3. Check focus order, visible focus, headings, landmarks and form labels.
4. Check contrast using USWDS tokens only.
5. Record findings and fixes in the deployment's conformance report.

# Standards

[WCAG 2.1 AA and Section 508](/standards/wcag-section-508.md) define the target. [USWDS](/standards/uswds.md) rules limit how fixes are made.
